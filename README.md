# BlueLink Party

<p align="center">
  <img src="web/icons/Icon-512.png" alt="BlueLink Party icon" width="140" />
</p>

A local multiplayer party game built with Flutter. Up to four phones on the same Wi-Fi network share one arena: the host runs the lobby and match simulation, and every device renders its own view of the action in real time.

## Game modes

| Mode | Players | Description |
| --- | --- | --- |
| **Battle Sync** | 2–4 (Red vs Blue) | Twin-stick arena battle, 1v1 or 2v2. |
| **Pixel Futbol** | 4 (2v2) | A full 2v2 football match with kick, bounce, and goal sounds. |
| **Screen Shift** | 2+ | Every device shows only its own slice of a shared arena — you can't see the whole field. |

## How it works

- **No server, no internet.** The host broadcasts a lobby over UDP on the local network; clients discover it, join, and claim team slots.
- **Host-authoritative.** The host runs the match simulation and streams position snapshots to clients over UDP. Clients send input (joystick / action buttons) back to the host.
- **Device-aware rendering.** All rendering is done against a virtual resolution and scaled per device, so the same snapshot looks right on any screen size.
- **Procedural audio.** All sound effects (`assets/audio/*.wav`) are generated by `tool/generate_sfx.dart` — there are no third-party audio assets.

## Getting started

Requires Flutter (Dart SDK `^3.12.2`).

```sh
flutter pub get
flutter run          # pick a device
```

Host one instance to start a lobby, then launch the app on 1–3 more devices on the same network and join from the lobby screen.

> On Android, the location / nearby-Wi-Fi permissions are requested at startup so the app can read the real Wi-Fi SSID. If denied, the network bar just shows "Unknown Wi-Fi"; multiplayer still works.

### Regenerating sound effects

```sh
dart run tool/generate_sfx.dart
```

### Running tests

Unit and logic tests, plus end-to-end tests that spin up real UDP host + client pairs over loopback:

```sh
flutter test
```

## Project structure

```
lib/
  main.dart                  Entry point: permissions, then the app
  app.dart                   MaterialApp + theme
  core/
    audio/sfx_service.dart   Audio playback for generated SFX
    theme/                   Dark acrylic theme, colors
  data/
    models/                  Game modes, lobby, match config, teams, slots...
    repositories/            Profile persistence, Wi-Fi info
  network/                   UDP host/client services, wire protocol, discovery
  features/
    player_setup/            Dashboard: name entry, mode selection, host/join
    lobby/                   Lobby screen + Bloc (slots, teams, start match)
    game/                    Battle Sync: Bloc, domain, sync adapter, painter
    battle_sync/             Shared arena logic + twin-stick controls
    matrix_arena/            Screen Shift: viewport slices, calibration overlay
    matrix_futbol/           Pixel Futbol match controller and arena
  dev/                       Internal device lab / matrix lab entries
tool/
  generate_sfx.dart          Procedural SFX generator
test/
  *_test.dart                Logic + loopback UDP e2e tests
```
